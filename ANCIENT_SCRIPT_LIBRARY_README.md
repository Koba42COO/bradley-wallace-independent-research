## 📖 How to Customize

### Adding New Scripts

1. **Copy a script card** from the HTML
2. **Replace glyphs** with new script symbols
3. **Update translation** with decoded meaning
4. **Adjust process steps** for specific methodology
5. **Update statistics** (age, accuracy, origin)

### Changing Colors

```css
/* In the <style> section */
:root {
    --gold: #ffd700;      /* Golden ratio highlights */
    --cyan: #4ecdc4;      /* Consciousness patterns */
    --red: #ff6b6b;       /* Prime numbers */
    --background: #1a1a2e; /* Main background */
}
```

### Adding Images

Replace emoji glyphs with actual images:
```html
<div class="glyph">
    <img src="path/to/glyph.png" alt="Glyph" style="width: 50px;">
</div>
```
